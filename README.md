## 四、按场景挑：四步选出适合你的套餐

如果你是第一次买，跟着这四步走基本不会买错。

1. **估负载**：纯静态博客、爬虫、Telegram 机器人这种轻量，1GB 或 2GB 够；WordPress + 插件、小型 SaaS、GitLab 这类，3.5GB 起步；跑数据库、Docker 多容器，直接 4GB 以上。
2. **选机房**：用户在欧洲选阿姆斯特丹或伦敦；用户在亚洲选洛杉矶 Asia 优化或新加坡；自己测试用选最近的节点。
3. **算账**：能年付就别月付，促销套餐年付单价能压到月付的一半以下，且续费锁定原价；月付只适合短期试用或负载不确定。
4. **下单后做几件事**：开 SSH key 登录、关密码登录、装 fail2ban、配防火墙、设自动备份脚本——基础套餐不带自动备份，这点要自己补。

讲个我自己踩的坑：第一次开 RackNerd 时图便宜买了 1GB 想跑 Minecraft 服务端，结果 5 个人在线就开始 swap，CPU 跑满。后来换 3.5GB 才稳。所以买之前真的得算清楚你的负载吃多少内存，别只看价格。
